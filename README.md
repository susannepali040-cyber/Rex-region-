# Rex Region — GBA Project

This is a **GBA source prototype** for your original Rex Region monster RPG.

Included:
- Rex, the white-haired trainer
- Flamcub, Aquafin, Leafling
- Evolution levels: 16 and 36
- Mega Evolution concepts
- 1,024 RexDex slots
- 16 gyms
- Map/world concept
- Costume system
- NPC/house/world references
- The Eclipse Story
- Varek / Team Eclipse
- Original GBA-style menus and battles

### Important
This ZIP is source code plus an automatic GBA build workflow. It is not a finished 1,024-creature commercial-scale game and does not include official Pokémon assets.

### Build from a phone
1. Create a GitHub repository.
2. Upload the files from this ZIP.
3. Open **Actions**.
4. Run **Build Rex Region GBA**.
5. Download the `Rex_Region_GBA` artifact.
6. Extract `rex_region.gba`.
7. Open it in a GBA emulator.

### Build on a computer
With devkitPro/devkitARM installed, run:

    make

Output:

    rex_region.gba
